# برنامه پیشرفته بررسی املا و نگارش فارسی و کردی

نسخه کامل با پشتیبانی از **دیکشنری آفلاین** + پیشنهاد کلمات + بررسی آنلاین.

## ویژگی‌های نسخه جدید

| ویژگی | توضیح |
|-------|--------|
| **دیکشنری آفلاین** | لیست کلمات رایج فارسی + کردی سورانی |
| **پیشنهاد هوشمند** | الگوریتم Levenshtein برای پیدا کردن کلمات مشابه |
| **قوانین نگارشی فارسی** | نیم‌فاصله، می/نمی، علائم نگارشی، حروف عربی |
| **بررسی آنلاین** | LanguageTool API (قابل خاموش کردن) |
| **دیکشنری شخصی** | افزودن کلمات و ذخیره دائمی |
| **غلط‌یاب سیستم** | فعال‌سازی SpellCheckConfiguration اندروید |
| **رابط RTL** | کاملاً راست‌چین |

## ساخت فایل APK

### پیش‌نیاز
- Flutter SDK نسخه ۳ به بالا
- Android SDK

### دستورات

```bash
# ۱. ورود به پوشه پروژه
cd persian_kurdish_spellchecker

# ۲. دریافت پکیج‌ها
flutter pub get

# ۳. ساخت APK
flutter build apk --release
```

فایل نهایی:
```
build/app/outputs/flutter-apk/app-release.apk
```

### نسخه کوچک‌تر (Split)

```bash
flutter build apk --split-per-abi --release
```

## افزودن دیکشنری بزرگ‌تر (اختیاری)

اگر می‌خواهید دیکشنری قوی‌تری داشته باشید:

1. یک فایل متنی با کلمات (هر کلمه در یک خط) بسازید.
2. آن را در پوشه `assets/` قرار دهید (مثلاً `persian_full.txt`).
3. در `pubspec.yaml` اضافه کنید:
   ```yaml
   flutter:
     assets:
       - assets/persian_common.txt
       - assets/persian_full.txt
   ```
4. در کد `main.dart` فایل جدید را هم بارگذاری کنید.

منابع پیشنهادی دیکشنری:
- فارسی: https://github.com/jadijadi/persianwords
- فارسی بزرگ: https://github.com/samanvp/persian-lexicon
- کردی: https://github.com/sinaahmadi/KurdishHunspell

## نکات

- بررسی آنلاین فقط برای فارسی کار می‌کند و نیاز به اینترنت دارد.
- دیکشنری شخصی در SharedPreferences ذخیره می‌شود.
- برای کردی سورانی فعلاً دیکشنری پایه وجود دارد. می‌توانید لیست کلمات خودتان را اضافه کنید.
